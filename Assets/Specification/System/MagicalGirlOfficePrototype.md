## 화면과 조작

최초 화면에 ‘마법소녀 사무소 / 7일 프로토타입’ 버튼을 둔다. 2026-09-23 사용자 피드백으로
사이드바 대시보드를 귀여운 가상 OS로 교체한다. 니디걸 오버도즈는 데스크톱 구성의 참고이며
실제 게임 이미지나 로고를 복제하지 않는다. 연보라·분홍·민트, 입체 테두리, 작은 픽셀형 앱 아이콘을 사용한다.
진입 시 열린 창 없이 바탕화면을 보여준다. 오늘의 업무, 일정, 인물 기록, 지역·사건,
메신저, 활동 기록, 설정 아이콘을 한 번 눌러 독립 창을 연다.
여러 창을 동시에 열고 제목줄 이동, 우하단 크기 조절, 최소화·닫기, 작업표시줄 복원,
클릭 시 앞으로 가져오기를 지원한다. 앱당 창은 하나이며 스크롤·선택 상태를 독립적으로 유지한다.
창은 작업 영역 안에 제한하고 최소 크기를 지킨다. 창 배치는 현재 세션 동안 유지한다.
오늘의 안건에서 두 대응안 중 하나를 선택하고 계획 확정으로 다음 날을 진행한다.
선택 이유·결과는 즉시 확인되며 이후 메시지와 활동 기록에 남는다. 미선택 상태로 진행하지 못한다.
7일차 확정 시 주간 정리와 인물별 후속 소식을 표시한다. 타이틀 복귀 및 확인을 거친 다시 시작을 제공한다.
작은 화면에서는 최소 논리 캔버스를 비례 축소하고 긴 창 내용은 스크롤한다.

### 모바일 터치 — 2026-09-23

- 창 내용 영역에서 한 손가락 드래그로 세로 스크롤한다. 8 화면 픽셀 이내 움직임은 탭으로 유지한다.
- 두 손가락이 같은 최상위 창에서 시작하면 손가락 간 거리 비율로 창 크기를 확대/축소한다.
  창 위치는 핀치 중심을 기준으로 조정하고 기존 최소 크기와 화면 경계를 지킨다. 글꼴 배율은 그대로다.
- 제목줄 한 손가락 드래그는 기존 창 이동을 유지한다. 마우스 휠과 크기 조절도 유지한다.
- 스크롤·핀치가 시작되면 합성 마우스 클릭을 차단한다. 핀치 후 한 손가락만 남아도 새 탭으로
  해석하지 않으며 모든 손가락을 뗀 후 다음 조작을 받는다. 다른 창으로 도중에 대상을 바꾸지 않는다.
- 전체화면 알림이나 토스트에서 시작한 터치는 뒤 창 제스처를 시작하지 않는다.
- 창별 스크롤은 내용 범위로 제한한다. 웹 캔버스에 touch-action:none을 적용해 브라우저 제스처와 경쟁하지 않는다.
- 실제 기기에서의 감도와 터치 전달 여부는 사용자 확인으로 남기며 웹/플레이 검증을 수행하지 않는다.

### 알림과 아이콘 연출 상세

- 우하단 토스트: 첫 진입의 새 안건, 선택 저장, 하루 진행 후 메시지 알림. 7초 후 닫히며
  직접 닫기 또는 관련 앱 열기가 가능하다. 토스트가 사라져도 안건은 앱에서 읽을 수 있다.
- 전체화면 팝업: 하루 확정, 진행 결과, 주간 종료, 초기화 확인. 화면 전체를 덮는 반투명
  레이어와 중앙 창을 사용하고 뒤 창·아이콘·작업표시줄 입력을 막는다. 필수 확인은 자동 닫기하지 않는다.
- 설정에서 팝업/토스트 미리보기 및 이펙트 켜기/끄기를 제공한다.
- 기존 Addressables의 radial-trapezoid, sparkle, ring, glow를 아이콘 뒤 레이어로 공유한다.
  새 안건·선택 아이콘 뒤에서 느린 회전·빛·반짝임을 표현하고 텍스트·클릭 영역을 가리지 않는다.
  리소스 로드 전에도 기본 아이콘은 보이며, 장식이 입력을 가로채지 않는다.
- 향후 앱 아이콘·장식 아이템 교체를 고려해 앱별 도형과 배경 이펙트 그리기를 분리한다.
  이번 범위에는 아이템 획득·상점·장착 등 게임 규칙을 추가하지 않는다.

## 작성된 7일 시나리오

인물 ID는 `office-hana`, `office-sori`, `office-yuna`; 이름은 하나, 소리, 유나.
하나는 공손하지만 업무 범위와 실적에 까다롭고, 소리는 기력이 낮아 최소한만 답하며,
유나는 갸루 말투로 친근하게 부탁하다가 규정을 밀어붙이기도 한다. 학교 발표, 회복,
졸업 준비라는 기존 사정과 인물 ID를 유지한다.
사건 ID `office-riverside-01`: 하천 산책로 이상 반응. 학교, 하천, 지원센터를 지역 목록으로 표현한다.

| 일차 | 안건 | 선택 0 | 선택 1 | 후속 |
|---|---|---|---|---|
| 1 | 하나의 일정 변경·실적 인정 요구 | 방과 후 조사와 제출 시각 지정 | 기관 이관·하나의 실적 제외 | 공손한 이의 제기, 추가 업무 선 긋기 |

선택에 따른 운영 방식·메시지 차이가 기록된다. 수치 경제·신뢰 자동 변화는 추가하지 않는다.
정보는 확인된 사실/본인 메시지/계획으로 구분하고 일차와 출처를 표시한다.

## 독립 저장과 전이

PlayerPrefs key `projectw.office.m1.v1`, JSON schema `1`, ScenarioId `office-seven-days`.
필드는 SchemaVersion(int), ScenarioId(string), Day(int 1–8), Choices(int[7], -1 미선택/0/1).
Day 8은 종료. Day 이전 선택은 필수, 미래 선택은 -1, 오늘 선택은 -1/0/1.
개별 안건의 영구 ID는 `office-day-1`…`office-day-7`; 배열은 이 고정 콘텐츠 순서를 저장하며 인물 식별에 쓰지 않는다.
선택과 하루 확정 시 저장한다. 불러오기에서 버전·식별자·범위·전이 검증 실패 시 원문을 보존하고
저장을 차단한 상태로 오류를 보여준다. 사용자가 명시적으로 초기화할 때만 해당 프로토타입 키를 지운다.
기존 campaign/desktop 키와 JSON 데이터는 읽거나 변경하지 않는다.
