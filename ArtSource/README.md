# ProjectW ArtSource

This directory contains selected authoring masters and generation records. Unity does not import it.

Keep experiments in `.utmp/art/`. Promote only reviewed, runtime-ready exports to
`Assets/MilestonePrototype/RemoteAssets` or, for an explicitly approved base-APK dependency,
`Assets/MilestonePrototype/LocalAssets`.

The authoritative directory, naming, format, and promotion rules are in
`Assets/Specification/Art/ResourceAssetPolicy.md`.
